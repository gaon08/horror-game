# 삐돌이가 사는 동굴

Three.js로 만든 1인칭 3D 동굴 공포게임입니다. 게임 화면은 브라우저 창을 가득 채우고 조작 안내는 아래에 작게 표시됩니다. 미로를 탐험해 열쇠 조각과 도구를 모으고, 삐돌이를 피해 탈출하세요.

## 실행 (Windows)

1. Python 3를 설치합니다.
2. 프로젝트 폴더에서 `START_GAME.bat`을 더블클릭합니다. 로컬 웹 서버를 켜고 브라우저에서 게임을 엽니다.
3. 게임을 마치면 최소화된 서버 창을 닫습니다.

`game.js`는 브라우저에서 불러오는 모듈이므로 더블클릭해 실행하지 마세요. Windows Script Host 오류가 뜨면 창을 닫고 `START_GAME.bat`을 실행하세요. Python 3가 설치되어 있지 않다면 [python.org](https://www.python.org/downloads/)에서 설치한 뒤 다시 실행하세요. Three.js는 jsDelivr에서 불러오므로 인터넷 연결이 필요합니다.

수동 실행을 원하면 프로젝트 폴더의 터미널에서 `py -m http.server 8000`을 실행한 뒤 브라우저에서 `http://localhost:8000`을 여세요.

## 조작

- 게임 화면에서 마우스 왼쪽 버튼을 누른 채 드래그: 시선 둘러보기
- `W` / `S`: 전진 / 후진
- `A` / `D`: 왼쪽 / 오른쪽으로 이동
- `←` / `→`: 마우스가 없을 때 시선 회전
- `Shift`: 달리기 (발소리가 커져 삐돌이의 주의를 끕니다)
- `E`: 가까운 물체와 상호작용, 열쇠 조합, 출구 열기
- `1` / `2`: 귀뚜라미 미끼 / 섬광탄 선택
- `Q`: 선택한 도구 사용
- `M`: 동굴 지도
- `Esc`: 일시정지

동굴에서 열쇠 조각 세 개와 생존 도구를 찾아 갈림길의 작업대에서 열쇠를 조립하세요. 귀뚜라미 미끼를 던지면 삐돌이가 먹이를 찾아와 먹는 동안 잠시 시간을 벌 수 있습니다. 가까운 거리에서 사용하는 섬광탄은 삐돌이를 잠시 기절시킵니다. 완성한 열쇠로 남동쪽 출구를 열면 탈출입니다.

Three.js가 암벽 미로, 1인칭 손전등, 동굴 소품과 직접 만든 입체 비어디드래곤 모델을 렌더링합니다. 시작 화면은 괴물의 실루엣과 붉은 조명으로 구성되어 있습니다.
